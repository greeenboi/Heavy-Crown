## API and database specification

### API

The service runs on port `8000` and exposes:

- `POST /items/` creates an item and returns `201 Created`.
- `GET /items/` returns all items.
- `GET /items/{item_id}` returns one item by ID.
- A missing item returns `404 Not Found`.

Item request and response fields:

```json
{
  "id": 1,
  "title": "Example item",
  "description": "Example description"
}
```

`id` is generated by the database. `title` and `description` are required
strings when creating an item.


### Database constraints

- The database is SQLite, stored at `/app/data/app.db`.
- The `items` table contains `id`, `title`, and `description`.
- `id` is an auto-incrementing integer primary key.
- `title` and `description` are stored as strings.
- `id` and `title` are indexed.
- The `/app/data` directory should be mounted as a Docker volume to preserve
  data when the container is replaced.
